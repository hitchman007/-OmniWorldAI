# OnlyWar Unity Production Core

This folder is the native 3D production track for OnlyWar. It does not replace the browser prototype.

Target:
- Unity 6 LTS
- iOS / iPadOS / Android / Windows
- Mobile-first landscape HUD
- 60 FPS target on mid/high devices with Low/Medium/High/Ultra profiles
- Multiplayer, Battle Royale and Extraction architecture
- Original OnlyWar art, maps, weapons, operators and vehicles

Open the folder as a Unity project or migrate Assets/OnlyWar into a Unity 6 LTS project. The bootstrap and editor builder can create a runnable combat scene without third-party art, while production art is supplied through prefabs and Addressables later.
